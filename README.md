# JobPacer.app Assets

Publicly hosted image assets for the official [JobPacer.app](https://jobpacer.app) website.

## Homepage images

The production homepage images are stored under `homepage-images/` and served through GitHub Pages.

## Header slides

The production website header slideshow images are stored under `header-slides/` as 2400 x 800 PNG files.

Public raw URL pattern:

```text
https://raw.githubusercontent.com/mmhoehn/jobpacer.app-assests/main/header-slides/{filename}
```
