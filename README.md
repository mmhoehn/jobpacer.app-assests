# JobPacer.app Assets

Publicly hosted image assets for the official [JobPacer.app](https://jobpacer.app) website.

## Homepage images

The production homepage images are stored under `homepage-images/` and served through GitHub Pages.

## Header slides

The production website header slideshow images are stored under `header-slides/` as 2400 x 800 PNG files.

Use the portrait-backed files under `header-slides/adaptive/` for GoDaddy. Their centered 2400 x 800 composition is preserved on desktop while the 2400 x 3000 canvas prevents GoDaddy's mobile `cover` crop from zooming and cutting off the slide content.

Public raw URL pattern:

```text
https://raw.githubusercontent.com/mmhoehn/jobpacer.app-assests/main/header-slides/{filename}
https://raw.githubusercontent.com/mmhoehn/jobpacer.app-assests/main/header-slides/adaptive/{filename}
```
